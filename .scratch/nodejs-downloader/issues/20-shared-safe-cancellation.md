# 20: 取消下载项而不误停其他下载

**What to build:** 用户能够取消指定下载项或未被其他下载使用的未完成文件；应用解释仍用于其他下载的文件为什么继续，并在正式提交或索引阶段完成必要安全步骤后结束取消。

**Blocked by:** 19 — 连续提交到跨目录共享有界并发队列。

**Status:** ready-for-agent
Labels: ready-for-agent

- [ ] 下载项取消撤销其有效需求引用，只停止不再被其他下载使用的排队/下载文件；其他项仍需的唯一文件任务继续，不重复停止或收尾。
- [ ] 界面说明“此下载已取消；这个文件仍用于你的另一项下载”，明确同一用户的重复下载复用，不暗示多人共享或取消失效。
- [ ] 单文件取消仅对没有其他下载使用的未完成文件开放；用于多项下载的文件不提供会停止所有相关项的入口，用户可分别取消下载项。
- [ ] 不新增下载页面取消全部队列、停止所有引用方、暂停或正式文件删除能力；已完成且校验通过的正式文件保留。
- [ ] 取消发生在正式文件提交或索引更新期间，先完成必要安全/一致性步骤，显示“取消处理中”及文件、目录或具体等待步骤，不截断提交。
- [ ] 必要索引协调失败时保留正式文件和旧索引，提示取消仍待一致性恢复及主动核验/协调动作，不误报收尾成功或镜像可交付。
- [ ] 仅处理可确认归应用管理的未完成临时文件，不触碰正式或未知内容；取消请求及关联结果能够由权威快照恢复展示。
- [ ] 应用 Interface 测试覆盖两个请求共享归档/清单/附件、取消其一仍继续、最后需求取消才停止、跨目录隔离及单文件入口限制。
- [ ] 真实临时目录与故障注入验证排队/下载/校验/正式提交/索引阶段取消，正式内容保留，错误与等待清晰，不以通知到达代替磁盘一致性。
- [ ] 正式界面演示共享项取消及安全阶段反馈；与后续主动索引恢复、状态持久化和退出票集成时保留上述取消语义。
