# 同一目标平台的分发变体支持范围

Type: grilling
Labels: wayfinder:grilling
Status: open
Blocked by: 01, 02
Assignee: none

本议题决定第一版如何面对同一操作系统与 CPU 架构下并存、不可互换的分发变体，不擅自扩大用户确认的选择范围。

## Question

官方清单已经出现 `linux-x64` 与 `linux-x64-musl` 等同一目标平台的不同分发变体。第一版是只支持 nvm 常用的标准变体，还是允许用户明确选择其他变体？如何避免把它们静默合并或错当成不同压缩格式？

依据 [官方版本目录与当前受支持 LTS 的判定依据](02-release-catalog.md)，与用户决定：

- 第一版的变体白名单/识别边界，以及未识别文件如何呈现。
- 标准变体之外的文件是否具备本地镜像内容准备价值，是否可供目标 nvm 客户端实际安装；不能以官方可下载等同于 nvm 默认可消费。
- 若包含多个变体，批量选择、默认勾选与原始路径展示如何保持清晰；实际交互在 [搜索、多选与目标平台组合的交互模型](04-selection-interaction.md) 中设计。
- 文件清单加载失败时是否暂不可选择、何时重试；禁止从四维组合推导不存在的文件。

加载 `grilling` 与 `domain-modeling`。本议题解决支持边界，后续交互原型展示已确认边界，不实现下载功能。
