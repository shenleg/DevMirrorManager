# 21: 解释下载故障并支持手动从头重试

**What to build:** 用户能看懂每个失败影响哪些文件、下载项和目录，知道哪些工作继续，并在条件恢复后主动从头重试；部分文件成功、目标不齐备、签名附件告警与索引未确认不会被混成一个成功结果。

**Blocked by:** 19 — 连续提交到跨目录共享有界并发队列。

**Status:** ready-for-agent
Labels: ready-for-agent

- [ ] 网络中断、清单获取/解析失败、SHA-256 不匹配、写入/空间故障及目录失联显示具体原因、受影响范围、仍可继续内容与下一步动作。
- [ ] 清单失败解释归档不能完成校验，不标为目标缺文件；hash 失败内容不能成为正式文件或支撑索引。
- [ ] 官方签名附件失败单独告警，其他条件满足的内容仍可用，不暗示已执行/通过 PGP 验证。
- [ ] 支持用户主动重试失败项，从头下载；无自动重试、断点续传、暂停或条件恢复后自动启动。
- [ ] 同路径冲突、损坏或无法安全核验提示原文件仍保留，需要应用外人工处理；反复重试不能授权覆盖、删除、正式文件重置或替换。
- [ ] 空间不足、不可写/失联目录仅停止依赖该条件的操作，其他目录独立任务继续；不猜测、改绑或创建替代路径。
- [ ] 重试继续遵循同根唯一文件任务与有效请求关联，不因再次操作创建并行重复写入；在其他项仍引用任务时保持关联和全局计量正确。
- [ ] 不齐备目标显示“部分文件成功，此目标尚不齐备”，索引错误显示“文件已保留，索引未确认，尚不可交付”；附件告警与必需文件不足分别呈现。
- [ ] 本次失败的未完成临时内容只有确认归应用管理才可处理，正式/未知文件保留，历史成功不作为此次核验依据。
- [ ] 通过应用 Interface、受控网络和实际临时目录注入各类故障，验证其他任务继续、主动从头重试、无自动恢复、hash 失败隔离及冲突保护。
- [ ] 正式界面演示部分失败与手动重试；按步骤记录实际结果，网络请求成功不能被当作镜像交付成功。
