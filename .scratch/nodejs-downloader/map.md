# 运行时镜像工具第一阶段：Node.js 决策地图

本文件索引第一阶段规划的已解决决策；未解决问题由同目录 `issues/` 中的子议题和依赖关系表达，后续阶段不混入本地图的待解决问题。

## Destination

形成一份可交给开发执行的 Tauri Node.js 桌面下载器规格：支持版本搜索与多选、当前受支持 LTS 筛选、系统/架构与文件格式选择、下载目录选择，准备符合约定 nvm 客户端消费契约的镜像内容，并使镜像索引反映实际已下载且校验通过的可用内容，以便后续上传 Nexus。
本地图仅规划运行时镜像工具的第一阶段；路线清晰后形成开发规格，不在本轮实现应用。Python/uv、Go/voidint/g 和 Nexus API 上传属于后续阶段。

## Notes

### 已确认的第一版范围

- 用户于 2026-10-13 确认补充需求及地图调整方案；本轮只更新规划文件，不授权应用实现、Git 提交或推送。
- 第一版必须包含 Node.js/nvm 镜像准备、当前受支持 LTS 与系统/架构筛选、目录选择，以及让版本管理工具按实际镜像可用内容发现版本。
- Node.js 发行版本和分发文件的上游固定为 `https://nodejs.org/dist/`；生命周期判定所需的官方数据依据见已完成调研，数据失效策略仍待决策。
- 下载器第一版运行于 macOS 和 Windows；运行平台不限制可下载的目标平台。
- 页面支持搜索、多选发行版本、仅显示当前受支持 LTS；排除已停止维护的历史 LTS 发布线。发行版本上的 LTS 标记和发布线的支持状态必须分别判断，搜索过滤器以查询时的“现在”为判定时间，不硬编码调研当天的支持状态。
- 保留已确认的选择维度：发行版本、操作系统、CPU 架构和文件格式；只允许真实存在的组合，批量版本可应用一组目标平台与文件格式。分发变体的支持范围仍待决策。
- 默认面向 nvm 所需的分发文件，不默认下载源码、安装器或所有附件；兼容客户端版本、必需格式与可选格式原则见 [部分镜像的索引、校验文件与可用性承诺](issues/05-partial-mirror-policy.md)，具体分发变体范围仍待决策。
- 用户选择输出根目录，内容保存到其下的 `nodejs/`，不固定到仓库目录。保留上游原始文件名与相对路径，不解压、不改名。
- 同时面向 nvm-sh 和 nvm-windows；后续 Nexus 上传应以 `nodejs/` 内的相对路径为基准。限定客户端与使用场景的消费契约已记录在 [部分镜像的索引、校验文件与可用性承诺](issues/05-partial-mirror-policy.md)；源码调研和路径相似不等于已通过实际客户端兼容验收。
- 用户明确补充需求中的“根据下载的内容列出内容”指版本管理工具消费镜像时的版本发现（A），不是新增应用镜像地址设置页或代为配置 nvm。镜像索引以实际已完成并通过校验的内容为依据，不能照搬上游全量索引并宣称未下载内容可用；某版本只备有部分系统/架构文件，也不能宣称其余组合可用。单一入口合并索引及其跨平台发现、别名和交付限制见 [部分镜像的索引、校验文件与可用性承诺](issues/05-partial-mirror-policy.md)；具体任务恢复和失败协调仍由后续议题决定。

### 后续需求（不属于本地图交付范围）

- Python 下载与 uv 镜像兼容：后续另行明确分发来源、文件路径、消费者版本和支持周期，不能直接套用 Node.js 目录或 LTS 规则。
- Go 下载与 `voidint/g` 镜像兼容：后续另行调查远端版本发现、归档下载与镜像配置契约。

## Decisions so far

<!-- 仅索引已解决子议题；已确认的需求范围记录在 Destination 与 Notes。 -->

- [nvm 双客户端与 Nexus 路径的兼容契约](issues/01-mirror-protocol.md)：固定客户端源码证实索引与压缩格式随版本/环境变化，当前 nvm-windows 标准安装需 `.7z`；Nexus 路径映射已查明，事实调研不代表端到端验收通过。
- [官方版本目录与当前受支持 LTS 的判定依据](issues/02-release-catalog.md)：LTS 标记须结合官方发布线时间表；分发文件以真实校验清单核对，索引类别不足以枚举格式，时间与分发变体边界留待用户决策。
- [Tauri 跨平台下载与输出目录的技术约束](issues/03-tauri-constraints.md)：Tauri 2 提供流式网络、文件与进度通信构件；恢复、校验、持久化与安全完成需自建规则，跨平台权限与构建限制已查明，尚未选择技术栈。
- [部分镜像的索引、校验文件与可用性承诺](issues/05-partial-mirror-policy.md)：采用单一入口合并索引，任一目标平台必需文件齐备且校验通过即可收录；接受跨平台发现与别名安装限制，固定客户端及格式、原始清单、重新核验与内容先索引后的交付契约。
- [下载任务的恢复、失败与完成语义](issues/06-download-lifecycle.md)：确定进度、取消、手动重试、批次并发、文件保护与校验、索引失败协调、目录变更及异常退出边界；并发上限和技术实现留待后续。
- [前端技术栈与下载引擎的职责边界](issues/07-implementation-boundaries.md)：确定 React/TypeScript 与 Tauri/Rust 的职责、结构化输入及最小权限、JSON 任务状态、单 crate 与窄测试接缝，以及 macOS/Windows 原生验证和构建路线。
- [生命周期数据失效与 LTS 筛选的边界策略](issues/09-lts-data-policy.md)：确定 UTC 日期边界、分离缓存与重判、未知状态的筛选处理、旧补丁提示及本机时钟承诺。

## Out of scope

- 本轮应用代码实现、实际下载 Node.js 大文件、应用打包发布；本轮只更新规划文件。
- 第一版 Python/uv、Go/voidint/g 下载与镜像支持；它们是项目后续方向，不是永久排除，也不是本地图的雾区。
- 第一版 Nexus 登录、API 仓库选择、上传、仓库创建和生产发布；API 仓库选择与上传已列为后续需求，本阶段只明确导出路径与消费前提。
- 第一版 Linux 桌面应用；下载 Linux 目标平台文件仍在范围内。
- Node.js 安装、解压、执行、切换本机版本，或替代 nvm 客户端；需求 A 不意味着应用代为配置版本管理工具。
- 第一版 npm 包镜像、额外运行时或非官方 Node.js 上游；后续运行时的来源与支持政策另行规划。
- 完整克隆 Node.js 上游全站；仅镜像用户选中的内容，不承诺其余版本或文件存在。
