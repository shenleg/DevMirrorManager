# 24: 统一关窗、退出与跨目录安全收尾

**What to build:** 用户关闭主窗口、菜单退出或使用退出快捷键时，应用按统一流程提示所有目录的未完成工作并安全收尾；失败与等待可解释，重开区分正常停止和异常中断，不关窗后台继续。

**Blocked by:** 23 — 重启后展示未完成工作并手动恢复。

**Status:** ready-for-agent
Labels: ready-for-agent

- [ ] macOS/Windows 主窗口及最后窗口关闭、菜单与快捷键退出进入同一流程；最小化继续，不添加托盘、后台服务或完成后自动退出。
- [ ] 无排队/进行中工作且无镜像一致性问题时直接退出；普通失败、取消或签名附件告警不冒充索引未确认问题。
- [ ] 有任务时提供“继续下载”和“停止并退出”，说明所有输出目录受影响、正式文件保留、重开不自动续传且未完成需手动从头重试。
- [ ] 提示期间任务继续，选择继续或关闭提示只放弃本次退出；确认后停止新派发，阻止新提交/重试，安全中断可中断下载/校验，不为退出下载剩余文件。
- [ ] 全局停止覆盖所有输出目录，唯一共享文件任务只停止/收尾一次；不在下载页面新增取消全部队列或改变平时共享取消语义。
- [ ] 正式提交及索引替换完成必要安全步骤，对已提交有效内容完成一致性处理，不中途截断写入；显示“正在停止并安全退出”及具体文件、目录与步骤。
- [ ] 重复退出复用当前流程；确认停止后不恢复原队列，返回应用只放弃退出意图，已停止工作不自动恢复，已开始收尾继续并限制冲突操作。
- [ ] 按镜像根列收尾结果，一个根失败不妨碍其他根安全收尾；整体安全退出要求全部相关写入结束且应用状态保存成功。
- [ ] 索引协调失败保留正式文件与旧索引，标记不可交付；写入结束且未完成状态保存成功后提供“返回应用处理”和需明确选择的“保留未完成状态并退出”，不要求先修好目录。
- [ ] 状态保存失败或仍有写入时不宣称安全退出，不提供绕过安全步骤的强制退出；长等待说明原因与路径，不固定超时强杀。
- [ ] 空闲但索引未确认时列目录并提示“返回应用”/“仍然退出”，仍要求无写入、保存成功及明确确认。
- [ ] 正常退出停止的未完成工作重开显示“已停止（应用退出）”，异常/系统强制中断遗留显示“已中断”；已有完成/失败/取消结果保留，不自动下载或协调。
- [ ] 应用 Interface 故障测试覆盖排队/下载/校验/提交/索引各阶段、共享任务、多根目录、重复退出、保存/协调失败、长等待及返回应用。
- [ ] 在 macOS/Windows 原生窗口演示空闲/有任务关窗、菜单/快捷键、最小化及重开，后续实际安装包复验；操作系统强制结束不计为正常安全退出成功。
