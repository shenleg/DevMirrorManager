# 26: 交付并原生验证 Windows x64 安装包

**What to build:** 内部使用者通过当前用户安装器安装 Windows x64 应用，已有 WebView2 可复用、缺少时得到联网安装及失败指引，并能安全使用、退出、升级和卸载而不丢失数据或镜像。

**Blocked by:** 18 — 按当前受支持 LTS 筛选发行版本；24 — 统一关窗、退出与跨目录安全收尾。

**Status:** ready-for-agent
Labels: ready-for-agent

- [ ] 在 Windows 原生环境构建 x64 当前用户 NSIS 安装包，提供普通启动与卸载入口；不提供 MSI、便携版或 Windows ARM64 下载器包，不依赖 macOS 交叉构建承诺。
- [ ] 应用本体按不需管理员运行设计，内部版暂不要求发行者签名，记录 SmartScreen 等实际提示与限制，不保证任意受管设备可运行。
- [ ] 检测复用已有 WebView2，缺少时采用官方 bootstrapper 联网安装，不带离线安装器/固定运行时；依赖可能受到额外授权或组织策略限制。
- [ ] 分别实际验证 WebView2 已有、缺少及安装失败；网络/权限/策略导致失败时明确报告并给官方指引，不能宣称应用安装成功且可用。
- [ ] 实际安装包在 Windows 10 22H2 与 Windows 11 验证并记录版本/架构/产物，缺环境记待验证，不以开发模式代替，不穷举系统补丁。
- [ ] 验证搜索、LTS、六目标预览、原生目录选择/取消、镜像准备及异常反馈，非管理员运行与仅选定目录写盘；Windows x64 运行不限制其他目标内容准备。
- [ ] 复验关窗、菜单/快捷键退出、最小化继续、退出提示/跨目录安全收尾、保存/协调故障和重开手动恢复，保留实际结果。
- [ ] 手动升级需退出旧版，占用时要求退出或阻止替换，不静默强杀；应用数据身份稳定，升级保留状态/镜像且重开不自动下载或协调。
- [ ] 通过真实升级及卸载/重新安装验证默认保留用户级数据和镜像；不提供卸载并删镜像，不仅凭 NSIS/Tauri 默认行为判断。
- [ ] 验证损坏/不兼容状态原文件保护、明确提示及确认后空状态，不删除镜像或自动执行旧任务。
- [ ] 提供中文安装、依赖、安全提示和手动升级说明；不要求关闭系统安全保护，不改 nvm/PATH/文件关联，不加开机启动、后台服务或自动更新。
- [ ] 每项记录环境、步骤、实际结果及证据，缺失/失败不计通过；仅内部交付，不公开发布，CI/CD、凭证、用户内容删除或外部发布另行确认。
