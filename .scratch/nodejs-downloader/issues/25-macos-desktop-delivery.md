# 25: 交付并原生验证 macOS 两架构安装包

**What to build:** 内部使用者无需开发环境即可安装 Apple Silicon 或 Intel 的 macOS 应用，理解首次打开限制，并安全使用目录选择、镜像准备及退出；手动升级和移除应用默认保留数据与镜像。

**Blocked by:** 18 — 按当前受支持 LTS 筛选发行版本；24 — 统一关窗、退出与跨目录安全收尾。

**Status:** ready-for-agent
Labels: ready-for-agent

- [ ] 在 macOS 原生环境分别产出 Apple Silicon 与 Intel DMG，包含可拖入 Applications 的应用；不做 Universal，不要求使用者装开发工具。
- [ ] 内部版采用 ad-hoc 签名，不要求 Developer ID、公证或账号/证书配置，不声称发行者已获系统认可或无安全提示。
- [ ] 提供中文首次打开说明，记录实际提示；仅说明用户确认信任且系统允许时的逐应用 Privacy & Security 流程，不关闭全局保护或绕过组织/恶意判定。
- [ ] 使用实际安装包验证两架构并覆盖 macOS 13 支持下限，记录实际系统/架构、产物版本和结果；缺环境记待验证，不用开发模式替代。
- [ ] 正式安装应用验证搜索、LTS、目标预览、原生目录选择及取消、下载/镜像结果反馈和路径保护；下载器运行架构不限制约定目标。
- [ ] 原生复验主/最后窗口、菜单/快捷键退出、最小化继续、退出提示/安全收尾和重开无自动下载/协调，包括故障反馈，不仅检查窗口能打开。
- [ ] 手动升级前结束工作并退出旧版，运行占用时要求退出或阻止替换，不热升级或静默强杀；稳定应用数据身份保持恢复关联与镜像。
- [ ] 通过真实升级/替换及常规移除应用验证默认保留应用数据和镜像，重新安装可读取兼容状态，不凭宿主默认行为推断数据保留。
- [ ] 实際验证损坏/不兼容状态保护、明确错误及经确认启用空状态，重置不删除镜像；完成、失败/取消与停止/中断语义保持正确。
- [ ] 不新增自动更新/联网应用更新检查、开机启动、后台、PATH、文件关联或 nvm 修改；应用不以管理员身份运行。
- [ ] 保留安装、首次打开、功能、退出、升级与数据保留的可追溯证据；失败明确记失败，缺环境明确记待验证，不声明未执行项目通过。
- [ ] 仅内部构建与原生验收，不公开发布；涉及用户目录删除、CI/CD、证书/密钥或外部部署等红线操作须另外确认，本票不是预授权。
