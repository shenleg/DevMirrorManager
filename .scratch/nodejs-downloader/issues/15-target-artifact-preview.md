# 15: 按目标平台预览真实必需文件

**What to build:** 用户单选发行版本后，能够浏览六个目标组合，并看到官方清单证实的必需文件及其准备条件；应用明确区分清单未就绪、清单失败和真实缺文件，不让无效选择进入后续下载链路。

**Blocked by:** 14 — 在桌面应用中浏览与搜索官方发行版本。

**Status:** claimed
Labels: ready-for-agent

- [ ] 系统与架构分别选择，覆盖 macOS、Windows、Linux 的 x64/ARM64；选项始终可浏览，下载器运行平台不限制目标选择，不展示支持比例。
- [ ] 对选定发行版本获取并解析官方 `SHASUMS256.txt`；只有成功清单才能证明具体必需文件存在或缺失，不能仅凭上游 `files` 类别或组合推导存在性。
- [ ] macOS/Linux 固定需要 `.tar.xz` 与 `.tar.gz`，Windows 固定需要 `.7z`；页面显示发行版本、目标和必需输出，不提供格式或变体选择控件。
- [ ] Linux 仅采用标准 x64/ARM64 分发文件，排除 musl 及其他范围外候选，不提供额外诊断列表；ZIP、安装器、源码不作为必需格式替代品。
- [ ] 未选发行版本、清单未就绪或获取/解析失败、任一必需格式缺失时不能提交；实际下载入口接入后必须复用该权威判定，不在本票创建假任务。
- [ ] 清单失败显示原因及用户主动重试入口，不标为目标不支持；其他已成功加载清单的发行版本仍可浏览。
- [ ] 搜索导致发行版本失配时清除发行版本、保留系统与架构，不自动选择替代发行版本；改选目标不静默改选发行版本。
- [ ] Rust 校验结构化发行版本和目标，依据固定官方来源及真实清单确定文件；伪造输入、非法相对路径或前端传入任意格式不能绕过领域规则。
- [ ] 清单原始字节与解析结果分别处理，为后续原样保存与 hash 校验保留正确依据，不裁剪清单以冒充镜像可用列表。
- [ ] 正式界面及应用 Interface 测试覆盖六目标、缺一种必需归档、musl 排除、清单加载/失败/重试、失配清除与恶意输入；固定样例不冒充官方某发行版本的事实。
