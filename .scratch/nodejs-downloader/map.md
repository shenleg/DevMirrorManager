# 运行时镜像工具第一阶段：Node.js 决策地图

Labels: wayfinder:map
Status: open

本文件索引第一阶段规划的已解决决策；未解决问题由同目录 `issues/` 中的子议题和依赖关系表达，后续阶段不混入本地图的待解决问题。

## Destination

形成一份可交给开发执行的 Tauri Node.js 桌面下载器规格：支持版本号前缀搜索与单选、当前受支持 LTS 筛选、系统/架构选择和下载目录选择；每次提交一个发行版本与一个目标平台，按固定必需格式直接加入共享有界并发队列；准备符合约定 nvm 客户端消费契约的镜像内容，并使镜像索引反映实际已下载且校验通过的可用内容，以便后续上传 Nexus。
本地图仅规划运行时镜像工具的第一阶段；路线清晰后形成开发规格，不在本轮实现应用。Python/uv、Go/voidint/g 和 Nexus API 上传属于后续阶段。

## Notes

### 已确认的第一版范围

- 用户于 2026-10-13 确认补充需求、单选流程及地图调整方案，授权更新规划与临时交互原型；不授权正式应用实现、Git 提交或推送。
- 第一版必须包含 Node.js/nvm 镜像准备、当前受支持 LTS 与系统/架构筛选、目录选择，以及让版本管理工具按实际镜像可用内容发现版本。
- Node.js 发行版本和分发文件的上游固定为 `https://nodejs.org/dist/`；生命周期判定所需的官方数据依据见已完成调研，数据失效策略见[生命周期数据失效与 LTS 筛选的边界策略](issues/09-lts-data-policy.md)。
- 下载器第一版运行于 macOS 和 Windows；运行平台不限制可下载的目标平台。
- 页面支持版本号前缀搜索：查询先去首尾空白、去可选前导 `v`，再按版本号文本前缀匹配（如 `22.1` 可匹配 `22.10`），结果按语义版本降序排列。发行版本单选；当前受支持 LTS 筛选仍排除已停止维护的历史 LTS，发行版本自身的 LTS 标记与发布线支持状态分别判断。搜索或 LTS 状态变化导致当前版本不再匹配时清除版本选择、保留系统/架构、不自动选择其他版本；不影响已提交请求。
- 每次提交只含一个发行版本和一个系统/架构目标，系统/架构下拉框可浏览。格式不作为选择维度：macOS/Linux 固定 `.tar.xz` 与 `.tar.gz`，Windows 固定 `.7z`，并获取原始 `SHASUMS256.txt` 及官方提供的签名附件；不提供可选格式控件，不展示支持比例。只有成功取得清单后才能判断必需格式缺失；清单未就绪/失败时禁用下载并显示错误与主动重试。已确认的交互细则与临时原型见[版本搜索、单选与目标平台的下载交互](issues/04-selection-interaction.md)；原型行为检查不代表正式应用或用户体验验收通过。
- 有效选择点击下载直接加入共享的有界并发队列；每次提交可分别汇总和取消但不构成串行屏障，同一文件及发行版本级校验/签名附件跨提交复用。页面显示发行版本、目标平台、必需输出和目录；尚未选择输出根目录时先打开目录选择器，取消不提交。下载前不弹确认对话框，但同路径文件冲突仍须停止并提示，不得静默覆盖或删除，也不新增正式文件重置/替换能力。队列和数据保护规则见[下载任务的恢复、失败与完成语义](issues/06-download-lifecycle.md)。
- 用户选择输出根目录，内容保存到其下的 `nodejs/`，不固定到仓库目录。保留上游原始文件名与相对路径，不解压、不改名。
- 消费客户端保留 nvm-sh 与 nvm-windows；Linux 按通用标准 `linux-x64` / `linux-arm64` 目标处理，不限定 Debian 等具体发行版，但仍排除 musl 变体；macOS nvm-sh 与 Windows nvm-windows 契约保留。后续 Nexus 上传应以 `nodejs/` 内的相对路径为基准。限定客户端与使用场景的消费契约已记录在 [部分镜像的索引、校验文件与可用性承诺](issues/05-partial-mirror-policy.md)；源码调研和路径相似不等于已通过实际客户端兼容验收。
- 用户明确补充需求中的“根据下载的内容列出内容”指版本管理工具消费镜像时的版本发现（A），不是新增应用镜像地址设置页或代为配置 nvm。镜像索引以实际已完成并通过校验的内容为依据，不能照搬上游全量索引并宣称未下载内容可用；某版本只备有部分系统/架构文件，也不能宣称其余组合可用。单一入口合并索引及其跨平台发现、别名和交付限制见 [部分镜像的索引、校验文件与可用性承诺](issues/05-partial-mirror-policy.md)；具体任务恢复和失败协调仍由后续议题决定。

## Decisions so far

<!-- 仅索引已解决子议题；已确认的需求范围记录在 Destination 与 Notes。 -->

- [nvm 双客户端与 Nexus 路径的兼容契约](issues/01-mirror-protocol.md)：固定客户端源码证实索引与压缩格式随版本/环境变化，当前 nvm-windows 标准安装需 `.7z`；Nexus 路径映射已查明，事实调研不代表端到端验收通过。
- [官方版本目录与当前受支持 LTS 的判定依据](issues/02-release-catalog.md)：LTS 标记须结合官方发布线时间表；分发文件以真实校验清单核对，索引类别不足以枚举格式，时间与分发变体边界留待用户决策。
- [Tauri 跨平台下载与输出目录的技术约束](issues/03-tauri-constraints.md)：Tauri 2 提供流式网络、文件与进度通信构件；恢复、校验、持久化与安全完成需自建规则，跨平台权限与构建限制已查明，尚未选择技术栈。
- [部分镜像的索引、校验文件与可用性承诺](issues/05-partial-mirror-policy.md)：采用单一入口合并索引，任一目标平台固定必需文件齐备且校验通过即可收录；不提供可选格式选择/追加能力，原样保留校验清单和官方签名附件；接受跨平台发现与别名安装限制，并维持重新核验及内容先于索引的交付契约。
- [下载任务的恢复、失败与完成语义](issues/06-download-lifecycle.md)：确定进度、取消、手动重试、跨提交共享有界并发与文件去重、文件保护与校验、同一镜像根索引更新串行协调、目录变更及异常退出边界；存在未完成写入时不可交付，具体并发上限和实现留待后续。
- [前端技术栈与下载引擎的职责边界](issues/07-implementation-boundaries.md)：确定 React/TypeScript 与 Tauri/Rust 的职责、单个版本/系统架构结构化输入及领域规则固定格式、最小权限、含共享文件任务和提交关联的 JSON 状态、单 crate 与窄测试接缝，以及 macOS/Windows 原生验证和构建路线。
- [生命周期数据失效与 LTS 筛选的边界策略](issues/09-lts-data-policy.md)：确定 UTC 日期边界、分离缓存与重判、未知状态的筛选处理、状态变化使所选版本不再符合筛选时清除版本但保留目标、旧补丁提示及本机时钟承诺。
- [同一目标平台的分发变体支持范围](issues/10-distribution-variants.md)：Linux 采用通用标准 `linux-x64` / `linux-arm64` 构建，不限定 Debian 等具体发行版并排除 musl 变体；分发变体不是选择维度，必需格式固定且无可选格式控件或批量目标门槛；范围外条目不展示诊断，清单失败由用户重试。

- [第一版桌面交付的安装、签名与更新要求](issues/12-desktop-release-requirements.md)：确定内部交付的运行平台与系统下限、分架构 DMG 和当前用户 NSIS、有限签名与首次运行限制、WebView2 联网依赖、手动升级与数据保留，以及原生安装包验收边界。
- [版本搜索、单选与目标平台的下载交互](issues/04-selection-interaction.md)：确认版本号前缀搜索、单选版本与目标、固定必需格式、筛选失配清除、目录选择和点击直接入共享并发队列；临时原型行为已验证，取消和异常反馈的决策见下一项。
- [下载队列结果与异常反馈的交互原型](issues/11-batch-feedback-prototype.md)：确认取消不影响其他下载所需文件、单文件取消入口边界、安全阶段取消及异常/部分结果/索引反馈；界面用“仍用于其他下载”解释去重关系，原型体验获认可，不代表正式应用或客户端验收通过。

## Out of scope

- 本轮正式应用代码实现、实际下载 Node.js 大文件、应用打包发布；本轮只更新规划与已授权的临时交互原型。
- 第一版 Python/uv、Go/voidint/g 下载与镜像支持；它们是项目后续方向，不是永久排除，也不是本地图的雾区。
- 第一版 Nexus 登录、API 仓库选择、上传、仓库创建和生产发布；API 仓库选择与上传已列为后续需求，本阶段只明确导出路径与消费前提。
- 第一版 Linux 桌面应用；下载 Linux 目标平台文件仍在范围内。
- Node.js 安装、解压、执行、切换本机版本，或替代 nvm 客户端；需求 A 不意味着应用代为配置版本管理工具。
- 第一版 npm 包镜像、额外运行时或非官方 Node.js 上游；后续运行时的来源与支持政策另行规划。
- 完整克隆 Node.js 上游全站；仅镜像用户选中的内容，不承诺其余版本或文件存在。
